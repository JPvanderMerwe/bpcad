# bpcad brand assets

Generated by `build_brand.py` in this folder. Geometry and colour come from one
source, so regenerating keeps web and native identical. Re-run with:

```
pip install cairosvg pillow fonttools --break-system-packages
python3 build_brand.py
```

## The mark

An isometric solid with a quarter section cut away, the exposed internal faces
lit in amber. A section view is the drafting convention for showing what is
inside a part, which is what the product does. The silhouette stays a clean
hexagon so it still reads at 16 px, and the amber notch carries the recognition.

Amber `#FFB000` is the period-correct amber phosphor value, chosen over terminal
green so it reads as a CAD workstation rather than a generic hacker skin.

## Tokens

| Name | Hex | Use |
|---|---|---|
| `case` | `#0B0F0D` | app and icon background |
| `bezel` | `#151B18` | panels |
| `etch` | `#2A322D` | rules, borders |
| `grid` | `#182019` | graticule |
| `phosphor` | `#FFB000` | primary accent, active state |
| `screen` | `#DCE3DC` | the printable part, primary text |
| `dim` | `#7C8880` | secondary text |
| `pen-dim` | `#4A554E` | construction geometry |

Section-cut shading uses `#C98A08` and `#8F6206` derived from `phosphor`.

## Files

**source/** — edit these, not the PNGs.
`icon-master.svg` full detail, use at 512 px and above.
`icon-small.svg` simplified with heavier strokes, use below 512 px.
`mark.svg` transparent mark for splash and adaptive foregrounds.
`mark-monochrome.svg` single colour with alpha tiers for Android themed icons.

**ios/** `AppIcon-1024.png` is the only one Xcode needs for a modern asset
catalogue. The rest are included for anything that still wants explicit sizes.

**android/**
`adaptive-foreground-432.png` and `adaptive-background-432.png` for
`ic_launcher.xml`. The mark sits inside the 72 dp safe zone, so it survives
circular, squircle and rounded masks.
`adaptive-monochrome-432.png` for themed icons on Android 13+.
`play-store-512.png` for the store listing.
`legacy-launcher-*.png` for pre-adaptive densities.

**web/**
`favicon.ico` (48/32/16), `icon-16/32/48/180/192/512.png`,
`icon-*-rounded.png` for places that do not mask,
`maskable-512.png` with the 20% safe margin PWA maskable icons require.

**splash/**
`splash-logo-1152.png` centred logo for `flutter_native_splash`.
`splash-logo-android12-960.png` for the Android 12+ splash API, which crops to a
circle, so keep the mark inside the middle two thirds.
`splash-1290x2796.png`, `splash-1179x2556.png`, `splash-1080x1920.png` full
composed screens if you would rather ship images than compose at runtime.
Splash background colour is `#0B0F0D`.

**social/** `og-image-1200x630.png` for Open Graph and Twitter cards,
`twitter-600x315.png` for the smaller summary card.

**wordmark/** light and dark SVGs with the glyphs as outlines, so no font is
needed at render time, plus 2400 px PNGs.

## Snippets

`web/manifest.json`:

```json
{
  "name": "bpcad",
  "short_name": "bpcad",
  "background_color": "#0B0F0D",
  "theme_color": "#0B0F0D",
  "display": "standalone",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/icons/maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]

```

```html
<link rel="icon" href="/favicon.ico" sizes="any">

<meta name="theme-color" content="#0B0F0D">
<meta property="og:image" content="https://YOUR_DOMAIN/og-image-1200x630.png">
```

## Licence note

The wordmark is set in JetBrains Mono Bold, licensed under the SIL Open Font
License 1.1, which permits use in a logotype. The glyphs are converted to
outlines in the SVGs, so the font is not redistributed. Keep a copy of the OFL
text with the project if you ship the font itself for UI text.

## Before you ship

Check the icon against a real home screen on both platforms, in light and dark
system themes, and in the app switcher. The 16 px favicon and the Android themed
icon are the two that break first if the mark is ever changed.
